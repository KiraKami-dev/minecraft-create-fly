# Create Aeronautics: Fabric 1.21.11 port (private, work in progress)

A port of [Create Aeronautics](https://github.com/Creators-of-Aeronautics/Simulated-Project) and its Sable physics
engine to **Minecraft 1.21.11 on Fabric**, on top of [Create Fly](https://github.com/ZurrTum/Create-Fly).

- **[ROADMAP.md](ROADMAP.md)**: setup, workflow, progress and open tasks. Start here.
- **[PORTING.md](PORTING.md)**: porting rules and the 1.21.1 → 1.21.11 API cheat sheet.
- Active development happens on the **`integration`** branch.
